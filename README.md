# quran-tafsir-data

Static tafsir data files served to the Quran app via jsDelivr.

- `zilal/` — في ظلال القرآن (سيد قطب), segmented by ayah range.
  - `manifest.json` — book metadata and checksums
  - `zilal.json.gz` — whole book (`{"book":…, "surahs":{"1":[{"from","to","text"}]}}`)
  - `surahs/{n}.json` — one surah (`{"surah":n,"segments":[{"from","to","text"}]}`); `from: 0` is the surah introduction

Generated by `tool/zilal/import_zilal.py` in the app repo.
